
# النسخ الاحتياطي والاستعادة

## القرار المعماري

لا حزمة Backup إضافية بهذه المرحلة - `mysqldump` الأصلي + نسخ ملفات كافٍ تمامًا لحجم هذا المشروع حاليًا، وأبسط اعتمادًا.

## ما يُنسَخ احتياطيًا

1. **قاعدة البيانات** (كل شيء).
2. **`storage/app/public`** - كل الملفات المرفوعة.
3. **`.env`** (بمكان آمن منفصل تمامًا - ليس داخل نسخة البيانات، وليس بـGit).

## أمر النسخ (مثال MySQL)

```bash
mysqldump -u [DB_USERNAME] -p [DB_DATABASE] | gzip > backup_$(date +%Y_%m_%d_%H%M%S).sql.gz
tar -czf storage_$(date +%Y_%m_%d_%H%M%S).tar.gz storage/app/public
```

لا تُخزَّن هذه الملفات داخل `public/` إطلاقًا - مجلد منفصل خارج Document Root كليًا.

## سياسة الاستبقاء (توصية)

- يومي: 7 أيام. أسبوعي: 4 أسابيع. شهري: 3-6 أشهر.

## نسخة خارج الخادم

نسخة على نفس الـVPS **غير كافية**. ارفع النسخ لتخزين متوافق مع S3 أو خدمة نسخ الاستضافة. لا يُخزَّن مفتاح التشفير داخل النسخة نفسها.

## الاستعادة

1. `php artisan down --secret="<قيمة-عشوائية-وقتية>"`.
2. `gunzip < backup_XXXX.sql.gz | mysql -u [DB_USERNAME] -p [DB_DATABASE]`.
3. فك `storage_XXXX.tar.gz` إلى `storage/app/public`.
4. `php artisan production:check`.
5. تحقّق يدوي: سجّل دخول Super Admin، تصفَّح مستخدمًا حقيقيًا.
6. `php artisan up`.

## اختبار الاستعادة دوريًا

نسخة لم تُختبَر استعادتها فعليًا **ليست نسخة موثوقة**. كرِّر خطوات الاستعادة على بيئة تجريبية منفصلة كل بضعة أشهر.
