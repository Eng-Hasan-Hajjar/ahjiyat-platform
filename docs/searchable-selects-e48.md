# E48 — القوائم المنسدلة القابلة للبحث على الخادم

بدأ التحسين بمحدّد الوسائط في منشئ السلاسل السينمائية، ثم عُمّم على القوائم الطويلة أو المتزايدة في لوحة الإدارة بطريقة قابلة لإعادة الاستخدام.

## المشكلة

القوائم القديمة كانت تحمّل الخيارات إلى المتصفح بإحدى طريقتين:

- `limit(N)` مع `pluck()`: أحدث 50 إلى 300 سجل فقط، ثم يبحث المتصفح داخلها. السجل رقم 201 لا يمكن الوصول إليه مهما كُتب في البحث.
- `pluck()` بلا حدّ: كل السجلات داخل HTML الصفحة، وتكبر الصفحة مع نمو البيانات.

## القاعدة الجديدة (مثبتة بالاختبار)

1. البحث يجري على الخادم ضمن **كل** السجلات المسموح بها قبل `LIMIT`.
2. عند الفتح بلا نص: عدد صغير من الأحدث (10 في المكوّن المشترك، 20 في حقول Filament، و30 نتيجة كحدّ أقصى لكل طلب بحث في Filament) مع الاختيار الحالي حتى لو كان قديمًا.
3. المطابقة جزئية بلا حساسية للحالة، وكل كلمة شرط (AND)، و`_` و`%` حرفان عاديان (`instr` لا `LIKE`).
4. الاختيار لا يحفظ شيئًا بنفسه: الحفظ يبقى بزر الصفحة الأصلي.
5. الصلاحيات والفلاتر التابعة وسلوك الإلزام والقيمة الافتراضية والاختيار المتعدد كما كانت.
6. المخرجات: الاسم والخصائص وما يميّز المكرر فقط، بلا مسارات تخزين ولا معرّفات داخلية.

## القطع القابلة لإعادة الاستخدام

| الملف | الدور | متى |
|---|---|---|
| `app/Support/Search/TextSearch.php` | مطابقة النص (كلمات، `instr`، حدود طول وعدد) | أساس كل بحث |
| `app/Support/Search/ModelPicker.php` | مزوّد عام لأي Eloquent بعقد المكوّن المشترك (صفحات Livewire) | محدّد خارج Filament Form |
| `resources/views/components/searchable-select/index.blade.php` + `assets.blade.php` | مكوّن Blade/Alpine: combobox بحقل بحث، تحميل/لا نتائج/تعذّر، تحميل المزيد، لوحة ضمن التدفق (لا تُقصّ) | صفحات Livewire المخصّصة |
| `app/Filament/Support/SearchableOptions.php` | يضيف بحث الخادم إلى `Select` في Filament (`getSearchResultsUsing` + `getOptionLabelUsing`) | حقول نماذج Filament |
| بحث Filament المدمج (`->relationship()->searchable()`) | للفلاتر `SelectFilter` المبنية على علاقة | فلاتر الجداول |

### مثال: حقل Filament

```php
use App\Filament\Support\SearchableOptions;

SearchableOptions::make(fn (Get $get) => Puzzle::query()->official()->where('is_active', true), label: 'title')
    ->apply(Forms\Components\Select::make('puzzle_id')->label('الأحجية')->required());
```

### مثال: صفحة Livewire مخصّصة

```blade
<x-searchable-select.assets />   {{-- مرة واحدة في أعلى الصفحة --}}
<x-searchable-select id="my-picker" wire:model.live="itemId" method="searchItems"
    :value="$itemId" :selected="$picked" allow-none placeholder="ابحث…" />
```

```php
#[Renderless]
public function searchItems(string $term = '', int $offset = 0, string $current = '', array $context = []): array
{
    abort_unless($this->canSearch(), 403);          // الصلاحية مسؤولية الصفحة
    return $this->picker()->search($term, $offset);  // ['items' => [...], 'total' => int, 'next' => ?int]
}
```

### كانت تبحث على الخادم أصلًا (لم تُمسّ)

أحداث المنافسة في قواعد المكافآت، وأحداث بطولات الفرق، وملف الداعم (المستخدم) في الداعمين، وفلتر الداعم في المساهمات.

## الاستثناءات وأسبابها

| الحقل | السبب |
|---|---|
| مسار الأحجيات (منشئ المسار): العناصر والمهام والتصنيفات في صفوف المستويات | **لم يُحسَّن في هذه الدفعة.** الصفحة تكرّر قائمة لكل صف مستوى وتشترك مع منطق منشئ E40؛ تغييرها يخاطر بسلوك الحفظ. القوائم محدودة حاليًا بـ 300 جائزة و200 مهمة و100 تصنيف، **وهي مقتطعة**. هذا أول مرشّح للدفعة التالية. |
| تصنيفات الأحجيات والعملات في الإنجازات وتعريفات المهام | قوائم قليلة يديرها الأدمن، وحجمها محدود بإعدادات المنصة |
| عملة المستويات وباقات العملة وأسعارها وحركات الجواهر | عدد العملات قليل ومحدود |
| إزالة دور الداعم في برنامج رعاية | محدود بأدوار برنامج واحد |
| مراحل الموسم في الإعلانات وعناصر المحتوى | مراحل موسم واحد فقط |
| التقدير الموسمي: الموسم السابق (40) والبرنامج (30 نشطًا) | الموسم السابق هو المجاور، والبرامج النشطة محدودة |
| قوائم الحالات والفترات والأسباب والاتجاهات | قوائم ثابتة صغيرة |
| واجهة المنصة (18 قائمة): ظهور الفرق وسياسة الانضمام، أسباب البلاغات، سنة قاعة المشاهير، عملة المحفظة ونوعها، تصنيف بلاغ المحادثة، قائمة المجموعات عند الحفظ، عملة الدعم، طريقة أرباح المبدع، تصنيف وصعوبة أحجية المبدع، نجوم كتّاب الموسم، معاينة المشاهد السينمائية | لا توجد قائمة طويلة متزايدة من قاعدة البيانات: إما قيم ثابتة، أو مجموعات مختارة، أو مشاهد قصة واحدة. قائمة مجموعات المستخدم عند الحفظ محدودة بـ `COLLECTIONS_MAX_SAVES` (300 لكل مستخدم) |
| تنقّل المشاهد السريع في المنشئ | مشاهد مراجعة واحدة |

## لا تغيير على

لا مسارات جديدة (فلا يتأثر `ai:local:coverage --strict`)، لا migrations، لا تغيير في Vite أو `npm run build` (الأصول داخل القالب)، لا تغيير في ترتيب مشاهد الأحجية أو بياناتها أو نظام رفع الوسائط.

## الاختبارات

`tests/Feature/SearchableSelects` (42 اختبارًا): SS-01..14 و38 الوسائط والغلاف، SS-15..18 الأحجية، SS-19..31 إعادة الاستخدام خارج السلاسل السينمائية، SS-32..37 التباين وإتاحة الوصول والاتجاه، SS-39..42 صفحتا الموسم والمسار. وتعديل واحد على `CinUxTest` UX-06 (لم تعد الصفحة تحمل المكتبة كـ `<option>`).

أعد الملفات المعدّلة من Git واحذف الملفات الجديدة (NEW في `SS-FILES.txt`) ثم `php artisan view:clear`. لا جداول ولا بيانات تتأثر.
