# الدردشة اللحظية (E21)

دردشة **نصية** بثلاثة أنواع مغلقة فقط: **مباشرة** (بين صديقين)، **فريق** (غرفة واحدة لكل فريق)، **عامة** (غرفة واحدة للمنصة)، مع غير مقروء وإشراف وبثّ لحظي عبر **Laravel Reverb**. الرسائل نص عادي (بلا HTML/Markdown/مرفقات).

## 1. البنية

| الجدول | الغرض |
|---|---|
| `chat_threads` | الغرفة. `type` ∈ direct/team/global. **direct:** ثنائي قانوني (المعرّف الأصغر `direct_user_one_id`، الأكبر `direct_user_two_id`) و`direct_key` = `"أصغر:أكبر"` **UNIQUE** ← A↔B وB↔A غرفة واحدة بقيد القاعدة. **team:** `team_id` UNIQUE ← غرفة رئيسية واحدة. **global:** `slug`=`global` UNIQUE ← غرفة عالمية واحدة. `last_message_id/at` لقوائم سريعة. هوية الغرفة **ثابتة** (حارس النموذج) |
| `chat_messages` | الرسائل. `body` نص، `edited_at`، `deleted_at` (حذف المرسل = Tombstone)، `hidden_at/by/reason` (إخفاء إشرافي). **لا حذف فعلي أبدًا** (حارس النموذج): النص يبقى لمراجعة البلاغات |
| `chat_read_states` | صف واحد لكل (غرفة، مستخدم): `last_read_message_id` (لا صف لكل رسالة × مستخدم). UNIQUE(thread,user). رتيب: لا يتراجع |
| `chat_message_reports` | بلاغ: تصنيف مغلق (spam/harassment/inappropriate/scam/other)، حالة pending/reviewed/dismissed/actioned، UNIQUE(message,reporter) |
| `chat_mutes` | كتم الدردشة العامة المؤقّت: `expires_at` بمدد مغلقة (10 د/ساعة/24 س/7 أيام)، سبب إلزامي، `lifted_at` للرفع |

الفهارس: `chat_messages(chat_thread_id,id)` للصفحات بالمؤشر، `(sender_id)`، `(thread,sender,created_at)` لحماية التكرار، `chat_threads(type,last_message_at)`، `chat_message_reports(status,id)`.

**الخدمات (`App\Services\Chat`):** `ChatAccess` (**مصدر الحقيقة الوحيد** لسياسات القراءة/الإرسال: يستعمله المتحكّمات والخدمات **والقنوات الخاصة**) · `ChatThreadService` (إنشاء كسول آمن من السباق) · `ChatMessageService` (إرسال/تعديل/حذف/صفحات/قراءة) · `ChatUnreadService` · `ChatModerationService` · `ChatReportService` · `ChatMuteService` · `ChatBroadcaster` · `ChatMessagePresenter` · `ChatRoomView`.

## 2. القواعد

### مباشرة (DIRECT)
- **أصدقاء مقبولون فقط** (مصدر الحقيقة: E16 `FriendshipService`). لا محادثة مع النفس. ثالث لا يصل لغرفة غيره (المشاهدة والإرسال بزوج «أنا، المستخدم» لا بمعرّف غرفة؛ وعمليات الغرفة/الرسالة تعيد 404 لغير المخوَّل).
- **الحظر** (بأي اتجاه): لا رسائل جديدة؛ **التاريخ يبقى** مقروءًا وتعطَّل الكتابة برسالة.
- **إلغاء الصداقة:** التاريخ يبقى مقروءًا للطرفين، لا رسائل جديدة: «لا يمكنك إرسال رسائل لأنكما لم تعودا أصدقاء.»
- **عودة الصداقة** (بلا حظر): **الغرفة نفسها** تعود قابلة للإرسال.
- **GET لا ينشئ شيئًا:** تُنشأ الغرفة عند أول إرسال مسموح.

### الفريق (TEAM)
- أعضاء الفريق **الحاليون** فقط يقرؤون ويرسلون (غيرهم 404). **الخروج يقطع الوصول فورًا** (العضوية تُفحص بكل طلب، والقناة تُعاد تخويلها)، والتاريخ يبقى بالقاعدة.
- **العودة:** يعود الوصول **ويرى تاريخ الفريق الحالي** (قرار موثَّق).
- **المالك/المشرف الحاليان** يخفيان رسالة مخالفة بسبب إلزامي (لا يعدّلان نصها أبدًا، ويستعيدانها). العضو العادي لا إشراف له.
- **الفريق المعطَّل:** قراءة فقط لأعضائه الحاليين.
- المدخل: زر «💬 دردشة الفريق» بصفحة الفريق (للأعضاء).

### العامة (GLOBAL)
- موثَّق + غير مجمَّد (لا قراءة للضيف). **المكتوم يقرأ ولا يرسل** (الكتم مستقل عن التجميد).
- **رسائل المحظورين** (بأي اتجاه) تُرشَّح من عرض المشاهد وحده؛ المصدر كامل.
- **حدود:** 10 رسائل/دقيقة + دفعة 3 كل 10 ثوانٍ (`chat-global-send`)، وحماية تكرار نفس النص خلال 60 ثانية.
- **الإشراف:** إخفاء/استعادة رسالة، كتم/رفع كتم مؤقت، كلها بسبب إلزامي ومدقَّقة.

### الرسائل
نص عادي 1–2000 محرف (`config/chat.php`)، يُقصّ وتُحذف محارف التحكم، والفارغ/المسافات مرفوض. **تعديل** رسالتك خلال 15 دقيقة (علامة «معدّلة»)، **حذف** رسالتك = Tombstone («تم حذف هذه الرسالة») والنص يبقى للمراجعة. الإخفاء الإشرافي لا يظهر نصه للعامة (للمشرف وحده ليقرّر الاستعادة).

## 3. الإشراف والبلاغات

- **البلاغ:** تصنيف مغلق، لا بلاغ عن رسالتك ولا عن ما لا تراه أو المحذوف، **بلاغ واحد لكل مستخدم لكل رسالة** (قيد قاعدة).
- **مركز البلاغات (Filament):** يعرض **الرسالة المبلَّغ عنها وحدها** (المرسل، المبلِّغ، نوع الغرفة، السبب، الحالة، الوقت). **لا تاريخ محادثة، ولا صندوق رسائل خاصة للمشرف:** لا يوجد مورد للرسائل أو الغرف أصلًا (يُختبر آليًا).
- **استثناء الإشراف:** بلاغ عن رسالة **خاصة** يتيح لصاحب `chat.moderate` إخفاء **تلك الرسالة فقط**؛ ولا يستطيع المساس برسالة خاصة غير مبلَّغ عنها.
- **صلاحيات:** `chat.reports.view` (عرض مركز البلاغات) و`chat.moderate` (إخفاء/استعادة/كتم/مراجعة). تُمنح لـ**المدير** تلقائيًا (سجل الصلاحيات)؛ امنحها لدور المشرف يدويًا من إدارة الأدوار. لا اعتماد على أسماء أدوار.
- **التدقيق** (`OperationalAuditService`): `chat_message_hidden`، `chat_message_restored`، `chat_user_muted`، `chat_user_unmuted`، `chat_report_reviewed`. **لا تدقيق لرسالة عادية**، ولا يحمل التدقيق نص الرسائل.

## 4. غير المقروء والشارة

مؤشر واحد لكل غرفة ومستخدم؛ **ردّك يعلّم ما قبله مقروءًا**. العدّ مفهرس ومقيَّد بسقف (99 → تُعرض «99+»)، يستثني رسائلك والمحذوفة والمخفية (وبالعامة المحظورين). المحادثات المباشرة تُعدّ **باستعلام مجمَّع واحد** (لا N+1)، والشارة تُحسب **مرة واحدة لكل طلب**. الغرفة العامة التي لم تُفتح بعد = 0 (لا «99+» لحساب جديد). **لا إشعار (E15) لكل رسالة** والدردشة لا تمنح اقتصادًا ولا XP ولا تقدّم مهام. الإشارات (mentions) والدفع (push) والبريد: مؤجَّلة.

## 5. البثّ اللحظي (Reverb)

- **المسار:** `HTTP POST ← تحقق ← صلاحية ← معاملة ← commit ← بثّ`. **البثّ لا ينشئ رسالة أبدًا.** الحدث `ShouldBroadcastNow` يُرسَل **بعد commit** (`DB::afterCommit`)، وأي فشل (Reverb متوقف) **يُلتقط ويُسجَّل بلا نص الرسالة** فتبقى الرسالة محفوظة والاستجابة ناجحة (والواجهة تعمل بـHTTP كاملًا بلا لحظية).
- **قنوات خاصة فقط:** `private-chat.{معرّف الغرفة العام ULID}` لكل الأنواع (حتى العامة: ليست قناة عامة مجهولة). التخويل (`routes/channels.php` ← `ChatThreadChannel`) يستعمل **`ChatAccess::canRead` نفسها**: direct = الطرفان، team = الأعضاء الحاليون، global = موثَّق غير مجمَّد.
- **الحمولة** آمنة للعامة: `id, thread, sender{public_id,name}, state, body, edited, created_at` فقط (لا بريد ولا هاتف ولا حقول أمان/إشراف). الرسالة المحذوفة/المخفية بلا نص.
- **الأحداث:** `message.sent` و`message.updated` (تعديل/حذف/إخفاء/استعادة). العميل يدمج بالمعرّف فلا تظهر الرسالة مرتين (استجابة HTTP + بثّ).
- **لا Presence ولا typing ولا آخر ظهور** (مؤجَّلة).

### التشغيل محليًا
```
composer require laravel/reverb          # مرة واحدة: يحدّث composer.json و composer.lock (فعلْه ثم أضف الملفين للالتزام)
npm install                              # laravel-echo و pusher-js بـpackage.json؛ يحدّث package-lock.json (يُلتزم أيضًا)
php artisan migrate
php artisan permissions:sync
php artisan db:seed --class="Database\Seeders\RolesAndPermissionsSeeder"
```
ثم بملف `.env` (قيم عشوائية لك؛ لا تلتزم بها):
```
BROADCAST_CONNECTION=reverb
REVERB_APP_ID=100001
REVERB_APP_KEY=<php -r "echo bin2hex(random_bytes(10));">
REVERB_APP_SECRET=<php -r "echo bin2hex(random_bytes(10));">
REVERB_HOST=localhost
REVERB_PORT=8080
REVERB_SCHEME=http
```
ثم **(مهم: متغيرات `VITE_REVERB_*` تُقرأ وقت البناء)**:
```
npm run build            # أو npm run dev
php artisan reverb:start --debug     # بنافذة منفصلة
php artisan serve
```
بدون `VITE_REVERB_APP_KEY` وقت البناء تعمل الدردشة بـHTTP فقط (بلا لحظية).

## 6. الإنتاج
انظر «الدردشة اللحظية (E21)» بـ`docs/production-deployment.md`: عملية `reverb:start` تحت Supervisor/systemd، وبروكسي عكسي يدعم WebSocket، والمتغيرات، والطابور.

## 7. المسارات
`GET /messages` (القائمة) · `GET|POST /messages/{user}` · `GET|POST /teams/{team}/chat` · `GET|POST /community/chat` · `GET /chat/threads/{thread}/messages?before=` (صفحات أقدم) · `POST /chat/threads/{thread}/read` · `PATCH|DELETE /chat/messages/{message}` · `POST /chat/messages/{message}/report|hide|restore`. كلها لموثَّق نشِط الحساب، التعديلات POST/PATCH/DELETE فقط (CSRF)، ولا GET يغيّر حالة.

## 8. الديمو
`php artisan db:seed --class=DemoQaSeeder` يشمل `DemoChatSeeder`: يوسف↔سارة (غير مقروء واحد) ويوسف↔ليان، دردشة «فرسان الشام» (10)، العامة (18 من 18 مستخدمًا، منها رسالتا لمى وفراس المحظورين لتجربة الترشيح)، بلاغ معلّق على رسالة إعلانية من خالد، ووسام مكتوم 7 أيام. التفاصيل بـ`docs/demo-qa-data.md`.

## 9. حدود معروفة ومؤجَّل
- **غير موجود عمدًا:** مكالمات، فيديو، مرفقات/صور/صوت، مجموعات خاصة، غرف يصنعها المستخدمون، سلاسل، تفاعلات، استطلاعات، معاينة روابط، إعادة توجيه، تشفير طرفي (**لا ادّعاء E2EE**: النص مخزَّن قابلًا للمراجعة)، إشراف بالذكاء الاصطناعي، دفع/بريد، اقتصاد/XP/مهام للدردشة.
- رسائل المحظور بالعامة تصل عبر البثّ ثم يرشّحها العميل بقائمة محمَّلة وقت فتح الصفحة (حظر جديد يُطبَّق بالعرض التالي).
- الإشراف على الرسائل **الخاصة** بالبلاغ فقط (لا تصفّح).
- مستخدم محذوف: تبقى رسائله وتُعرض «حساب محذوف».
- التحقق من `reverb:start` يتطلب تثبيت الحزمة بجهازك (انظر الأداة `verify-e21.ps1`).
