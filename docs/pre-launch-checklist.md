
# قائمة ما قبل الإطلاق

## DNS / SSL

- [ ] النطاق يشير للخادم الصحيح.
- [ ] شهادة SSL فعّالة.
- [ ] `APP_URL` يطابق النطاق بـ`https://`.

## البيئة

- [ ] `APP_ENV=production`, `APP_DEBUG=false`.
- [ ] `php artisan production:check` بلا فشل حرج.

## قاعدة البيانات

- [ ] مستخدم DB مخصَّص (ليس root).
- [ ] كل الترحيلات مُنفَّذة.

## النسخ الاحتياطي

- [ ] آلية نسخ احتياطي مجدوَلة فعليًا.
- [ ] نسخة Offsite واحدة على الأقل.
- [ ] استعادة تجريبية واحدة نجحت فعليًا.

## التخزين

- [ ] `storage:link` مُنفَّذ (Symlink حقيقي).
- [ ] رفع صورة تجريبي يعمل ويظهر بالواجهة العامة.

## البريد

- [ ] SMTP حقيقي مضبوط - أو قرار واعٍ بتأجيله.

## الطوابير والجدولة

- [ ] Cron الفعلي مُفعَّل.
- [ ] Worker يعمل إن أُضيفت أي Job مستقبلية.

## الكاش

- [ ] `config:cache`/`route:cache`/`view:cache` نُفِّذت بنجاح.

## الصلاحيات

- [ ] `config/permission.php` و`config/permissions.php` موجودان معًا.

## صفحات الأخطاء

- [ ] 403/404/419/429/500/503 عربية احترافية.

## التحليلات

- [ ] `/admin/analytics` يعمل، التصدير يعمل.

## الإدارة

- [ ] Super Admin حقيقي بكلمة سر قوية.
- [ ] `/admin` و`login`/`register` تحمل `noindex`.

## الرفع

- [ ] `robots.txt` يعكس `seo.indexing_enabled` الفعلية.

## المراقبة (توصية خارجية)

- [ ] Uptime Monitor خارجي على `/up`.
- [ ] تنبيه انتهاء صلاحية SSL.
- [ ] تنبيه امتلاء القرص.

## الاختبارات

- [ ] `docs/smoke-tests.md` نُفِّذت كاملة.
