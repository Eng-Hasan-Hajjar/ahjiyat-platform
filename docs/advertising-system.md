# نظام الإعلانات والرعاية (E14)

## المبدأ الأول: الإعلانات اختيارية بالكامل
المنصة تعمل كاملة بلا أي إعلان. `ads_enabled=false` (الافتراضي بأي تثبيت جديد)
يعني: صفر سكربت، صفر تتبُّع، صفر فراغ بالتخطيط. لا حساب Google ولا CMP
مطلوبين لتشغيل المنصة الأساسية إطلاقًا.

## البنية
- **AdPlacement**: نقطة عرض معروفة بالكود (`AdPlacementRegistry`)، تُفعَّل/تُعطَّل فقط من الإدارة.
- **SponsorCampaign**: اتفاق راعٍ مباشر. `status` هو مصدر الحقيقة الوحيد: `draft → pending_review → approved/rejected`، و`approved → paused ⇄ approved`.
- **SponsorCreative**: المادة المعروضة (حقول مُهيكَلة فقط، صفر HTML/JS).
- **AdImpression/AdClick**: تتبُّع Append-Only للراعي المباشر فقط، إجمالي بحت، صفر هوية مستخدم.

## مفاتيح التحكُّم (Platform Settings)
| المفتاح | الافتراضي |
|---|---|
| `ads_enabled` | false |
| `direct_sponsors_enabled` | false |
| `external_ads_enabled` | false |
| `max_ads_desktop` | 2 |
| `max_ads_mobile` | 1 |

## المواضع الأساسية الحالية
- `home_inline_primary`: الصفحة الرئيسية، بعد المحتوى الرئيسي.
- `leaderboard_sidebar`: لوحة الصدارة، أسفل القائمة (الاسم البرمجي تاريخي - لا شريط جانبي فعليًا بالتصميم الحالي أحادي العمود).

لم تُضَف "صفحة نتائج" لعدم وجود سطح عرض نتيجة منفصل معماريًا - نتيجة حل
الأحجية تظهر ضمن نفس صفحة اللعب المحمية بالكامل.

## مواضع محظورة صراحةً (أبدًا)
اللعب التفاعلي، الحملات، المهام، التقدُّم، المتجر، المحفظة، المخزون،
تسجيل الدخول/التسجيل، الإعدادات/الخصوصية، لوحة الإدارة.

## النشر مع تعطيل الإعلانات بالكامل
```
ADSENSE_CLIENT_ID غير مطلوب أصلًا
```
اترك `ads_enabled=false` (الافتراضي) — المنصة تعمل بلا أي خطوة إضافية.

## تفعيل الرعاة المباشرين فقط
1. `ads_enabled=true`, `direct_sponsors_enabled=true`.
2. أنشئ حملة من Filament، أرفق مادة واحدة على الأقل، أرسلها للمراجعة.
3. مستخدم آخر بصلاحية `ads.campaigns.review` يعتمدها.

## تفعيل Google AdSense
**حالة هذا الإصدار: منفَّذة بالكود، مُعطَّلة تشغيليًا عمدًا.** راجع
`docs/advertising-brand-safety.md` و`docs/advertising-privacy-consent.md`
للأسباب والخطوات التشغيلية المتبقية قبل أي تفعيل حقيقي.

## E14.1 - ثوابت التصحيح النهائي

- **سلالة الاعتماد:** الحملة المعتمَدة **والمُوقَفة** كلتاهما "سبق اعتمادها". أي تغيير بمحتواها (إنشاء/تعديل/حذف مادة، أو تغيير اسم الراعي) يُعيدها إلى `pending_review` ويمحو `approved_by/approved_at`. يُفرَض بالنموذج نفسه (`AdInvariantGuard`) فلا يتجاوزه Filament ولا Tinker ولا Seeder. الاستئناف (`resume`) لا يعمل إلا من `paused`، فلا يصل إليه أي تغيير محتوى.
- **الاعتماد/الإرسال/الاستئناف** يُعيدون فحص: موضع معروف واحد على الأقل، مادة نشطة واحدة على الأقل، روابط HTTPS آمنة، جدولة صحيحة (البداية قبل النهاية)، اسم الراعي والحملة - من قاعدة البيانات لحظة التنفيذ. الاستئناف لا يشترط أن تكون الحملة داخل نافذتها الآن (العرض يبقى مشروطًا بـ`now()`).
- **حماية السجل التحليلي:** مفاتيح `ad_impressions/ad_clicks` الأجنبية `RESTRICT`. حذف مادة/حملة/موضع له تاريخ مرفوض بالنموذج وبقاعدة البيانات. لا تُحذف حملة إلا إن كانت مسودة/مرفوضة وبلا تاريخ.
- **صلاحية الإعدادات:** تعديل أي مفتاح `advertising.*` يتطلب `ads.settings.manage` حصرًا (Super Admin يتجاوز). من يملك `settings.update` فقط يعدّل الإعدادات العامة ولا يستطيع تعديل الإعلانات، حتى بحمولة معدَّلة. التغييرات تُدقَّق (`ads.settings.changed`).
- **حاجز الاختبارات:** `tests/TestCase.php` يرفض التشغيل إن كان `config:cache` مفعّلًا أو كانت قاعدة الاختبار غير `database/testing.sqlite` أو `:memory:` أو قاعدة اسمها `*_test/*_testing`، قبل أي `migrate:fresh`.
