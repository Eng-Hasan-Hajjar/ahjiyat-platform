# دوري كتّاب الموسم وتقدير الداعمين (E44)

> نطاق E44: **(1)** دوري كتّاب موسمي يُرتَّب بنجوم الجمهور، **(2)** تقدير الداعمين بنقاط دعم وبطاقات حقيقية الدفع (فضي/ذهبي/ماسي).
> لا يضيف حزم Composer ولا npm، ولا دور مستخدم جديدًا، ولا محرك دفع ثانيًا. التشغيل اليومي: [دليل التشغيل](seasonal-recognition-operations-runbook.md).

## 1. القرارات الملزمة (ملخص)

| الموضوع | القرار |
|---|---|
| الكاتب | `CreatorProfile` معتمد **يُختار لموسم** (`season_writer_entries`). لا دور جديد ولا هوية مبدع ثانية. |
| السعة | الافتراضي 20، الحد الصلب 100 (ثابت منتج وقيد في الخدمة). |
| سلاسل الكاتب | ربط صريح (`season_writer_series`) لسلاسل `CreatorSeries` الظاهرة للكاتب نفسه. لا ربط بسلسلة مبدع آخر. |
| أهلية تصويت اللاعب | **خاصة بالكاتب**: محاولة موثَّقة (`CommunityPuzzleAttempt`، صحيحة أو خاطئة) على عمل داخل سلسلة مربوطة بهذا الكاتب لهذا الموسم وضمن نافذة التصويت. مشاهدة الصفحة لا تكفي. |
| المشرفون | صلاحية `seasonal-recognition.vote` (بلا شرط لعب). |
| الكتّاب | يصوّتون لكتّاب آخرين بقواعد اللاعب نفسها؛ **التصويت لنفسه ممنوع**. |
| الميزانية | **ميزانية واحدة = 10 نجوم لكل مستخدم في الموسم**، لا تتضاعف بتعدد الصفات (لاعب + مشرف + كاتب). التوزيع 0..10 لكل كاتب، يُعاد قبل الإغلاق ويُجمَّد بعده، والخادم هو السلطة. |
| الإغلاق | `voting_closes_at ≤ نهاية الموسم الفعلية − 7 أيام`. بلا نهاية صالحة ⇒ الجاهزية تفشل ولا يُفعَّل الدوري. |
| الترتيب الحيّ | من مجاميع مخزَّنة تُحدَّث داخل معاملة التصويت؛ **دفتر التوزيعات هو السلطة** وقابل لإعادة البناء. |
| الإنهاء | أمر صريح متكرر الأمان (`SeasonWriterFinalizer`) يثبّت المرتبة والنجوم والناخبين والنتيجة. أول ثلاثة: أول/ثاني/ثالث. |
| «خارج الموسم التالي» | آخر 5 (قابل للضبط 0–20) من غير أصحاب المراكز؛ **يسري على قائمة الموسم التالي المباشر فقط** — ليس حظرًا ولا إيقافًا ولا يمسّ الملف أو المحتوى. |
| الاستقطاب | غير منفَّذ في E44 (مؤجَّل). |
| جوائز الكتّاب | تجميلية عبر `InventoryService`؛ المالية **التزام قابل للتدقيق فقط** (`pending_finance`) يُسوّى يدويًا بمرجع. لا دفع آلي ولا تحويل عملات ولا مساس برصيد المبدع. |

## 2. نقاط الدعم (Support Points)

- **ليست** مالًا ولا جواهر ولا خبرة ولا نقاط تمريرة ولا درجة منافسة ولا أرباح مبدعين؛ لا تُصرف ولا تُحوَّل ولا تمنح أي أفضلية لعب.
- مصدران فقط: **(أ)** شراء متجر مُنفَّذ: `store_item_prices.support_points` (الافتراضي 0 = السلوك القديم)، تُلتقط لقطةً في `store_purchases.support_points_snapshot` وقت الإنشاء؛ **(ب)** بطاقة داعم محقَّقة الدفع.
- الدفتر `season_support_point_entries` إلحاقي فقط: `source_key` فريد ⇒ **منح واحد لكل مصدر**؛ الاسترداد يضيف **قيدًا سالبًا واحدًا** (`reverses_entry_id` فريد) بقيمة لقطة المنح الأصلي لا الإعداد الحالي.
- نقاط المتجر العامة تذهب إلى **موسم واحد مؤهَّل** (`supporters_enabled` ∧ حيّ ∧ لم يُنهَ). صفر مواسم ⇒ لا نقاط (والشراء ينجح). أكثر من موسم ⇒ **لا تخمين**: لا منح، مخالفة في المطابقة، تنبيه في السجل.
- مشتريات المتجر تبقى بالعملة الداخلية؛ E44 لا يغيّر سعرها ولا ما تمنحه.

## 3. بطاقات الداعم

| المستوى | السعر (USD) | الوحدة الصغرى |
|---|---|---|
| فضي | 25.00 | 2500 |
| ذهبي | 100.00 | 10000 |
| ماسي | 250.00 | 25000 |

- الدفع **الحقيقي** عبر E30/E32 بلا محرك جديد: `SponsorshipPayment` ← تحقق ← `SponsorshipContribution` على برنامج رعاية يستهدف الموسم. السعر والعملة والنقاط والنمط من الباقة على الخادم؛ العميل يرسل هوية الباقة فقط.
- **رفع الإثبات لا يمنح شيئًا.** التحقق وحده يُفعّل البطاقة ويمنح نقاطها. الاسترداد يعكس مرة واحدة بالضبط ويُعاد حساب المستوى.
- مستوى البطاقة = أعلى باقة **نشطة** غير مستردة؛ كل الباقات تُسهم بلقطة نقاطها.
- الخصوصية (E30): `is_public` لقطة وقت المنح. المجاميع العلنية تستثني مصادر المجهولين. الحسابات ذات ملف داعم E30 غير علني/موقوف/مؤسسة **تُستبعد من الأسطح العامة**، ويظهر المجهول «داعم مجهول».
- نمط الاسم الموسمي (ماسي > ذهبي > فضي > عادي): **طبقة عرض مشتقّة** برموز من قائمة بيضاء (`data-season-style`) يترجمها CSS الموقع؛ لا CSS حر. لا يمسّ العناصر التجميلية المملوكة. شارة «داعم الموسم #N» ديناميكية وليست `StoreItem`. شارة E30 العامة لا تتكرر بجوار الاسم نفسه.
- التنويه الاجتماعي = **طابور إداري** (eligible/queued/published/skipped) بلا ربط بأي واجهة خارجية.
- الترتيب العلني: **لاعبون فقط، أعلى 100**، بالنقاط العلنية تنازليًا ثم أقدم أول نقطة ثم المعرّف. يبقى مفتوحًا حتى نهاية الموسم ثم يثبّته `SeasonSupporterFinalizer` (مرتبة/نقاط/مستوى علني).

## 4. المخطط (ترحيلات إضافية فقط)

| الجدول | الدور |
|---|---|
| `season_recognition_settings` | إعدادات الموسم (مفاتيح، سعة، نافذة، خطة جوائز، علامات الإنهاء) |
| `season_writer_entries` | عضوية الكاتب في الموسم + المجاميع الحيّة + لقطة الإنهاء |
| `season_writer_series` | ربط سلاسل الكاتب بالموسم |
| `season_writer_vote_budgets` | ميزانية واحدة لكل (موسم، مستخدم) |
| `season_writer_star_allocations` | دفتر التوزيع (فريد لكل ناخب/كاتب) |
| `season_writer_awards` | قرارات الجوائز |
| `season_supporter_packages` | باقات البطاقات |
| `season_supporter_cards` | بطاقة = دفعة E32 واحدة + لقطة السعر/النقاط/النمط |
| `season_support_point_entries` | دفتر نقاط الدعم (إلحاقي) |
| `season_supporter_stats` | مجاميع كسولة + طابور التنويه + لقطة الإنهاء |
| أعمدة | `store_item_prices.support_points`، `store_purchases.support_points_snapshot` |

كل المفاتيح الأجنبية للتاريخ `RESTRICT`؛ لا float/decimal؛ أسماء فهارس صريحة ≤ 64. الجداول ذات الالتزام المالي/ربط المستخدم مسجَّلة في `FinancialHistoryGuard` (`season_writer_entries`، `season_writer_awards`، `season_supporter_cards`).

## 5. التزامن

محقَّق على MySQL حقيقي بمسبار عمليات متوازية (`tools/e44/concurrency-probe.php`، انظر [دليل التشغيل](seasonal-recognition-operations-runbook.md#7-التحقق-الحي-من-التزامن)) وبخطوة CI لمخطط MySQL.

- **التصويت**: قفل `budget` (حصري) ← `settings` (مشترك) ← `entry` (حصري). صف الميزانية يُنشأ كسولًا بـ`upsert` (قفل حصري مباشر) لا `INSERT IGNORE`، لأن الثاني يأخذ قفلًا **مشتركًا** ثم يُرقَّى فيتجمّد طلبان متزامنان لناخب واحد (1213). توزيعات الناخب لا يغيّرها غير طلباته نفسها وهي متسلسلة بقفل ميزانيته، فتُقرأ قراءةً عادية بعد القفل (لا `FOR UPDATE` على صف غير موجود: قفل الفجوة يتعارض عند الإدراج بين ناخبين). أول قراءة عادية في المعاملة تأتي بعد القفل كي ترى آخر ما التُزم به.
- **المُنهيان**: يقفلان `settings` حصريًا ثم صفوف الكتّاب/الإحصاء بترتيب المعرّف، ويجهّزان كل قراءة عادية (الحملة، حالة الموسم) **قبل** المعاملة كي لا تُثبَّت لقطة أقدم من الأقفال (وإلا خرج الترتيب من لقطة لا تطابق النقاط المختومة). قفل المدى يحجب إدراج صفوف إحصاء جديدة أثناء الإنهاء.
- **النقاط**: صف الإحصاء يُنشأ كسولًا بـ`upsert` ثم يُقفل أولًا؛ علم الإنهاء يُقرأ بعد القفل. منحٌ بعد الإنهاء يُلغى بالتراجع عن المعاملة كلها (لا قيد ولا صف إحصاء يتيم بلا ختم). العكس المتأخر يعدّل الأرقام الحيّة فقط.
- **إعادة المحاولة**: معاملات التصويت والمنح والعكس تُعاد حتى 3 مرات عند جمود نادر (بلا أثر جانبي: الكاش والبثّ والإشعار بعد الالتزام). المسبار يعدّ أي جمود ظاهر كخلل لأنه يرصد ما قبل إعادة المحاولة بالأقفال نفسها.
- **الحواجز النهائية**: فرادة `source_key` و`reverses_entry_id` والدفعة والتوزيع.
- آثار ما بعد الالتزام (بثّ/كاش/إشعار) عبر `DB::afterCommit` معزولة الفشل.

## 6. الواجهات والصلاحيات

- العلنية: `seasonal.writers.show|standings|stars`، `seasonal.supporters.show|standings|cards.store` (القراءة عامة؛ التصويت وطلب البطاقة لمستخدم موثَّق).
- الإدارة: صفحة Filament **واحدة** «التقدير الموسمي» بثمانية تبويبات (الكتّاب، التصويت، الترتيب النهائي، جوائز الكتّاب، باقات الداعمين، ترتيب الداعمين، طابور التنويه، المطابقة).
- الصلاحيات: `seasonal-recognition.view|manage|vote|audit|finalize|award`.
- مفتاحان مستقلان (الافتراضي معطَّلان): `SEASON_WRITERS_ENABLED` و`SEASON_SUPPORTERS_ENABLED`، إضافةً إلى مفتاح لكل موسم. **التعطيل يوقف الإجراءات الجديدة فقط** ولا يمحو تاريخًا.
- البثّ: قناة عامة تجميعية (`seasonal-writers.{id}` / `seasonal-supporters.{id}`، حدث `leaderboard.updated`) بلا هوية مصوّت ولا مبالغ؛ استطلاع احتياطي دائم.

## 7. الاستثناءات والقيود المعروفة

- «خارج الموسم التالي» يُحسب بين غير أصحاب المراكز؛ في قوائم صغيرة جدًا قد يقلّ العدد الفعلي عن الضبط (يمكن ضبطه 0–20).
- نمط الاسم والشارة الديناميكية يتبعان تفعيل التقدير في الموسم الحيّ الوحيد المؤهَّل؛ عند الغموض أو التعطيل لا يُعرضان (التاريخ والدفاتر واللقطات تبقى).
- ظهور «خارج الموسم التالي» علني في ترتيب الموسم نفسه ولا يُنشر على ملف المبدع.
- لا إعلان اجتماعي آلي، ولا استقطاب، ولا دفع آلي للجوائز المالية.

## 8. مرجع رموز الأسباب

كل رفض من خدمات E44 يحمل رمزًا ثابتًا (`SeasonalRecognitionException::$reason`) ورسالة عربية للمستخدم؛ الرموز مستقرة ويعتمد عليها الاختبار والواجهات.

| الرمز | المعنى |
|---|---|
| `forbidden` | الصلاحية المطلوبة غير متوفرة للفاعل |
| `finalized` | الدوري/الترتيب أُنهي؛ لا تغيير في الإعدادات أو إعادة بناء |
| `settings_unavailable` | تعذّر تجهيز صف إعدادات الموسم الآن |
| `invalid_previous` | الموسم السابق المختار غير صالح |
| `invalid_<حقل>` | مدخل إعداد غير صالح (بادئة `invalid_` + اسم الحقل) |
| `no_season_end` | لا نهاية صالحة للموسم أو لحملته؛ لا يمكن حساب آخر موعد إغلاق |
| `week_rule` | إغلاق التصويت يجب أن يسبق نهاية الموسم الفعلية بسبعة أيام على الأقل |
| `window_order` | إغلاق التصويت يجب أن يلي فتحه |
| `window_locked` | بدأ التصويت؛ موعد الفتح لا يتغير |
| `budget_locked` | لا تُغيَّر ميزانية النجوم بعد بدء التصويت |
| `capacity_below_roster` | السعة لا تقل عن عدد الكتّاب الحاليين |
| `capacity_full` | بلغت القائمة السعة أو الحد الصلب (100) |
| `reward_plan_too_long` | خطة الجوائز تتجاوز الحد الأقصى للبنود |
| `reward_plan_invalid` | بند جائزة غير صالح |
| `reward_item_invalid` | جائزة تجميلية بلا عنصر متجر تجميلي قابل للتسليم |
| `reward_amount_invalid` | جائزة مالية بلا مبلغ صحيح بالوحدة الصغرى أو بعملة غير مسموحة |
| `creator_not_eligible` | لا يُضاف إلا مبدع معتمد بحساب سليم |
| `duplicate` | المبدع في قائمة الموسم أصلًا |

| `duplicate_link` | السلسلة مربوطة بالكاتب أصلًا |
| `too_many_series` | بلغ الكاتب الحد الأقصى للسلاسل المربوطة |

| `unlink_locked` | لا يُلغى ربط سلسلة بعد فتح التصويت |

## 9. الاختبارات والتحقق

- **الأمر المحلي الوحيد (SQLite):** `vendor/bin/pest --compact tests/Feature/SeasonalRecognitionE44` — يغطي الإعدادات والقائمة، التصويت وميزانية النجوم، لوحة الصدارة والصفحات العامة والبث، الإنهاء والجوائز، نقاط الدعم وبطاقات الداعم ولوحتهم، صفحة Filament، بذور Demo، ميزانيات الاستعلامات، والحرّاس (عزل الاقتصاد، المسارات، الصلاحيات، الترحيلات، الوثائق، CI).
- **MySQL (في CI فقط):** خطوة واحدة لـ`E44MysqlSchemaTest.php` (القيود والفهارس المسمّاة وفريدات «ميزانية واحدة لكل ناخب» و«توزيع واحد لكل كاتب وناخب» ومسارات الكتّاب والداعمين الكاملة) + خطوة مسبار التزامن الحقيقي `tools/e44/concurrency-probe.php` (انظر [التحقق الحي من التزامن](seasonal-recognition-operations-runbook.md#7-التحقق-الحي-من-التزامن)).
- **لا تُشغَّل** مجلدات الاختبارات القديمة ولا الحزمة الكاملة لأجل E44: التراجع الواسع ملك CI الحالي. تُنفَّذ ملفات تاريخية بعينها فقط إن عدّل E44 صنفًا مشتركًا تعتمد عليه.
