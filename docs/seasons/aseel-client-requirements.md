
# متطلبات المحتوى من العميل — موسم أصيل (جاهزة لاجتماع العميل)

هذا الملف منظَّم حسب فئة المحتوى، لا حسب رقم الخطوة، لتسهيل مراجعته باجتماع واحد. كل حقل هنا **قابل للتعديل من لوحة الإدارة مباشرة** بلا حاجة لأي مطوّر.

## 1) الهوية (Branding)

| العنصر                                                 | الحالة الحالية         | مكان التعديل بالإدارة                                 |
| ------------------------------------------------------------ | ----------------------------------- | ------------------------------------------------------------------------ |
| شعار الموسم (Logo)                                 | غير مرفوع                   | المواسم الرسمية → أصيل → الهوية البصرية |
| صورة الغلاف الرئيسية (Hero Banner)         | غير مرفوعة                 | نفس القسم                                                        |
| صورة غلاف الحملة (تظهر بالبطاقات) | غير مرفوعة                 | الحملات → أصيل                                               |
| الجملة التعريفية (Tagline)                    | Placeholder جاهز للتعديل | المواسم الرسمية → أصيل                                |
| نمط الثيم البصري                               | مضبوط على "أصيل"        | نفس الحقل                                                        |

## 2) القصة (Story)

- العنوان الكامل والوصف التسويقي: Placeholder جاهز، يحتاج اعتماد نهائي.
- كل النصوص السردية الثمانية (نداء، القبول، الإرهاق، لجين، تحدي الفرق/الشطرنج كنصوص مؤقتة، النهاية): Placeholder احترافي، قابل للتعديل الفوري من "إدارة القصة → Stage → Gate → Step".
- شخصية "لجين" ودورها: **غير محسومة إطلاقاً** بالموجز الأولي.

## 3) الصور (Images)

| الغرض                                                       | الحالة                                      | ملاحظة                                                        |
| ---------------------------------------------------------------- | ------------------------------------------------- | ------------------------------------------------------------------- |
| صورتا مكتب أصيل (Spot Difference)                   | Placeholder مولَّد آليًا               | **أولوية قصوى** - أول ما يراه اللاعب |
| صورة دليل الغرفة                                   | Placeholder مولَّد آليًا               |                                                                     |
| صورة أدلة الحيوانات                             | Placeholder مولَّد آليًا               |                                                                     |
| المدينة/الإحداثيات (لغز "أي مدينة؟") | نص فقط، لا صورة معلم حقيقية | يحتاج معلمًا حقيقيًا                              |

## 4) الصوت (Audio)

- مقطعان صوتيان مطلوبان (Steps 12، 15) - **لا ملفات فعلية حاليًا**، المسارات موجودة بالبيانات فقط وتظهر كلوحة "سيُضاف قريبًا" حتى تُرفَع.
- صيغة مقترحة: MP3.

## 5) الأحجيات (Puzzles)

كل إجابات الأحجيات الـ13 حاليًا Demo منطقية (مثال: رمز الدفتر = 24، اسم الحساب المشفَّر = "اصيل") - قابلة للتعديل الفوري بحقل "الإجابة الصحيحة" بكل أحجية، بلا أي كود.

## 6) المكافآت (Rewards)

كل خطوة أحجية تملك حقل "سياسة المكافأة" (وراثة الأحجية الطبيعية / جائزة مخصَّصة / بلا جائزة) وحقل قيمة الجواهر - كلها مضبوطة بقيم Demo معقولة الآن، قابلة للتعديل الفوري.

## 7) التأهّل (Qualification)

البوابة الأولى فقط تحمل شرط "أول 100 مستخدم" - رقم Demo قابل للتعديل الفوري من "إدارة القصة → البوابة الأولى → العدد المسموح".

## 8) الفرق (Team) — قرار تقني معلَّق

لا نظام حقيقي منفَّذ عمدًا. الخطوة ظاهرة بمكانها الصحيح بالقصة كنص "قيد القرار التقني" فقط. **يحتاج قرار العميل قبل أي تنفيذ فعلي** (راجع الأسئلة).

## 9) الشطرنج (Chess) — قرار تقني معلَّق

نفس وضع الفرق تمامًا - لا محرك حقيقي أو وهمي، نص Placeholder فقط بمكانه الصحيح.

## 10) التكامل الاجتماعي (Social)

لا تكامل حقيقي (Instagram أو غيره) بهذه المرحلة - الخطوة المرتبطة (Step 19) تستخدم أحجية نصية بديلة حاليًا.

## 11) الجائزة الكبرى (Grand Prize)

**غير محدَّدة** - الواجهة تعرض تلقائيًا "سيتم الإعلان عن الجائزة الكبرى قريباً" حتى يُدخَل نص بالحقل المخصَّص بصفحة الموسم.
