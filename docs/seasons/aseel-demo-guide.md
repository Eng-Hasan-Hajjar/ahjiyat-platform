
# دليل عرض الديمو للعميل — موسم أصيل (15 دقيقة)

## قبل العرض

```bash
php artisan migrate
php artisan db:seed --class="Database\Seeders\Seasons\AseelSeasonSeeder"
```

**ملاحظة مهمة (E3)**: الـSeeder الآن آمن تمامًا — إن كنت قد عدَّلت أي محتوى من لوحة الإدارة سابقًا (نصوصًا، صورًا، مكافآت)، إعادة تشغيل هذا الأمر **لن تمسح تعديلاتك** إطلاقًا. يكفي تشغيله مرة واحدة فقط لإنشاء الهيكل الأساسي، ثم التعديل من Filament بأمان بعدها للأبد.

## خطوات العرض (15 دقيقة)

1. سجّل دخول `/admin`.
2. افتح **الحملات → المواسم الرسمية → أصيل**.
3. غيّر **الشعار (Logo) أو الغلاف (Banner) أو الجملة التعريفية** أمام العميل مباشرة.
4. احفظ.
5. اضغط **"معاينة الموسم"** (يفتح تبويب جديد).
6. اعرض **Hero اللاعب** - أشِر أن ما عدَّلته للتو ظهر فورًا.
7. مرّر لأسفل، اعرض **خريطة القصة الكاملة (22 مهمة، 3 مراحل)**.
8. افتح **خطوة سردية** (Narrative) - اقرأها، اضغط "متابعة القصة".
9. العب **Spot Difference** ("أثر في المكتب") - أشِر لتسميتي "قبل"/"بعد" وعدّاد "وجدت X من Y".
10. ارجع لصفحة الموسم - أظهر **تحديث نسبة التقدّم** فورًا.
11. أظهر **المكافأة** الممنوحة (الجواهر) بصفحة الأحجية أو بالمحفظة.
12. اشرح **First-N** (أول 100 متأهّل) عبر فتح البوابة الأولى بلوحة الإدارة، وأظهر شارة "تأهّلت - الترتيب #N" إن كان الحساب التجريبي قد تأهّل.
13. اعرض خطوة **Reflection** - اكتب إجابة، أظهر العدّاد الحي، أرسل، أظهر رسالة الشكر.
14. ارجع لخريطة القصة، أشِر لخطوتي **"تحدي الفرق"/"تحدي الشطرنج"** - اشرح بوضوح أنهما ظاهرتان بمكانهما الصحيح لكنهما **بانتظار قرار تقني من العميل نفسه**، وليستا ميزتين وهميتين.
15. اطلب **ملاحظات العميل** مباشرة (استخدم `aseel-client-feedback-checklist.md` كقائمة تذكير أثناء النقاش).

## ما يجب التأكيد عليه أثناء العرض

- كل تعديل بلوحة الإدارة (خطوة 3) ظهر فورًا باللاعب - نظام حقيقي، ليس Mockup.
- التقدّم والمكافآت والتأهّل جميعها محسوبة سيرفريًا فعليًا.
- خطوتا الفرق/الشطرنج لا تعملان بشكل وهمي - معلَّقتان بوضوح بانتظار قرار العميل، ولا يمكن نشر الموسم بشكل نهائي علنًا قبل حسمهما (نظام الجاهزية بلوحة الإدارة يمنع ذلك تلقائيًا).

## بعد العرض

راجع `docs/seasons/aseel-client-questions.md` مع العميل، واملأ `docs/seasons/aseel-client-feedback-checklist.md` بملاحظاته الفعلية.
