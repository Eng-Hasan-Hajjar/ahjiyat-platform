# دليل تشغيل التقدير الموسمي (E44)

> مرجع المشغّل لدوري كتّاب الموسم وتقدير الداعمين. القواعد في [الدليل التقني](seasonal-writers-supporters-e44.md).

## 1. قبل التفعيل (مرة واحدة)

1. `php artisan migrate` (ثلاثة ترحيلات إضافية فقط) ثم `php artisan db:seed --class=RolesAndPermissionsSeeder` (الصلاحيات الست؛ آمن للتكرار).
2. اضبط المفتاحين العامين في بيئة الإنتاج ثم `php artisan optimize` و`php artisan queue:restart` و`php artisan reverb:restart` (راجع [متغيرات البيئة](environment-variables.md)). الافتراضي **معطَّل** لكليهما.
3. لا مهام مجدولة جديدة ولا طوابير جديدة: الإنهاء والتسوية إجراءات إدارية صريحة.

## 2. دوري الكتّاب: دورة الموسم

1. **الإعداد**: من «التقدير الموسمي ← الكتّاب»: فعّل الدوري للموسم، حدّد السعة (≤100)، وفتح/إغلاق التصويت (**الإغلاق قبل نهاية الموسم الفعلية بسبعة أيام على الأقل**)، وعدد «خارج الموسم التالي»، وخطة الجوائز، ثم الموسم السابق إن لزم.
2. **القائمة**: أضف الكتّاب (مبدعون معتمدون بحسابات سليمة)، واربط لكل كاتب سلسلة واحدة على الأقل؛ بلا سلسلة لا يستطيع اللاعبون التصويت له (تنبيه جاهزية). القائمة تُقفل عند فتح التصويت.
3. **الجاهزية**: كل البنود الإلزامية يجب أن تنجح قبل فتح التصويت. غياب نهاية صالحة للموسم يمنع التفعيل.
4. **التصويت**: لا تدخّل. راقب «التصويت» (مجاميع فقط، بلا هوية ناخب).
5. **بعد الإغلاق**: راجع «المطابقة». أي مخالفة حاجبة تمنع الإنهاء حتى تُعالَج (إعادة بناء المجاميع من الدفتر).
6. **الإنهاء**: «الترتيب النهائي ← معاينة ← تأكيد ← إنهاء». لا رجعة بعده ولا يُعاد فتح التصويت.
7. **الجوائز**: التجميلية تُمنح تلقائيًا بعد الإنهاء (إعادة المحاولة من «جوائز الكتّاب» عند الفشل). **المالية تظهر `pending_finance`**: ادفع خارج النظام ثم سجّل التسوية بمرجع إلزامي. لا دفع آلي.

## 3. الداعمون: دورة الموسم

1. أنشئ **برنامج رعاية** E30 يستهدف الموسم، ثم «باقات الداعمين ← إنشاء الباقات الافتراضية» (فضي 25 / ذهبي 100 / ماسي 250 USD)، وفعّل التقدير للموسم.
2. اضبط نقاط الدعم لكل خيار سعر في المتجر (`نقاط دعم الموسم`)؛ 0 يعني السلوك القديم.
3. طلب بطاقة ← الداعم يدفع ويرفع الإثبات ← **تتحقق أنت من الدفعة** (مسار E32 القائم) ← تُفعَّل البطاقة وتُمنح النقاط تلقائيًا. رفع الإثبات وحده لا يمنح شيئًا.
4. الاسترداد (E32) يعكس النقاط ويعيد حساب المستوى تلقائيًا، مرة واحدة فقط.
5. بعد **انتهاء الموسم**: «ترتيب الداعمين ← إنهاء» لتثبيت المرتبة والنقاط والمستوى العلني.
6. «طابور التنويه» تسجيل يدوي فقط (لا ربط بأي شبكة اجتماعية).

## 4. المطابقة (قراءة فقط)

```
php artisan seasonal-recognition:reconcile            # كل المواسم التي لها إعدادات
php artisan seasonal-recognition:reconcile "demo-e44-recognition"   # موسم واحد: ضع slug الموسم الفعلي بين علامتي اقتباس (في PowerShell لا تكتب أقواس الزاوية < >)
```

الرمز 1 = توجد مخالفات. **لا خيار إصلاح في الأمر عمدًا.** الإصلاح من «التقدير الموسمي ← المطابقة» بإجراء صريح مسجَّل في التدقيق:

| المخالفة | المعنى | الإجراء |
|---|---|---|
| `entry_aggregate_mismatch` / `budget_mismatch` | مجموع كاتب/ميزانية لا يطابق الدفتر | «إعادة بناء مجاميع الكتّاب والميزانيات» (قبل الإنهاء) |
| `allocation_without_budget` / `self_vote_allocation` / `allocation_cross_season` | توزيع غير ممكن عبر الخدمة | تحقيق يدوي؛ لا حذف تلقائي |
| `roster_over_capacity` | عدد الكتّاب فوق السعة المضبوطة | ارفع السعة (≤100) أو اسحب كاتبًا قبل فتح التصويت |
| `closing_window_rule` | إغلاق التصويت مضبوط لاحقًا من آخر موعد مسموح | عدّل موعد الإغلاق قبل الإنهاء |
| `final_snapshot_incomplete` / `final_ranks_not_contiguous` | لقطة الكتّاب النهائية ناقصة أو مراتبها غير متصلة | تحقيق يدوي؛ اللقطة لا تُعدَّل |
| `stat_points_mismatch` / `negative_total` | إحصاء داعم لا يطابق دفتر النقاط | «إعادة بناء الإحصاءات» (قبل الإنهاء) |
| `entry_without_stat` | قيد نقاط بلا صف إحصاء | «إعادة بناء الإحصاءات» |
| `reversal_mismatch` | عكس لا يطابق قيده الأصلي (قيمة/مستخدم/موسم/خصوصية) | تحقيق يدوي؛ الدفتر إلحاقي ولا يُعدَّل |
| `card_active_without_grant` | بطاقة نشطة بلا منح نقاط | تحقيق يدوي؛ لا منح تلقائي لبطاقة نشطة |
| `card_pending_payment_verified` | بطاقة معلّقة ودفعها محقَّق (تفعيل فاته) | «تفعيل البطاقات المحقَّق دفعها» |
| `card_refunded_not_reversed` | بطاقة مستردة لم تُعكس نقاطها | تحقيق يدوي؛ العكس يتم من مسار الاسترداد |
| `card_payment_mismatch` | دفعة لا تطابق لقطة البطاقة (مبلغ/عملة/مستخدم) | تحقيق مالي؛ لا تُفعَّل البطاقة قبل حسمه |
| `store_purchase_without_grant` | شراء متجر منفَّذ بلقطة نقاط لكن بلا منح (منه غموض الموسم) | عطّل التقدير في المواسم الزائدة ثم أعد المطابقة؛ التعويض من «المطابقة ← منح شراء فائت إلى هذا الموسم» (رقم الشراء) إلى الموسم المختار صراحةً (E44 لا يخمّن) |
| `store_purchase_refunded_not_reversed` | شراء متجر مسترد بمنح لم يُعكس | تحقيق يدوي؛ العكس يتم من مسار الاسترداد |
| `supporters_snapshot_incomplete` | ترتيب الداعمين مُنهى وبعض صفوفه بلا ختم الإنهاء | تحقيق يدوي؛ اللقطة لا تُعدَّل |

## 5. الإيقاف الطارئ

- أوقف التصويت/البطاقات الجديدة: عطّل المفتاح العام أو مفتاح الموسم. **لا يُمحى أي تاريخ** (قوائم، أصوات، ترتيب نهائي، بطاقات، دفاتر).
- لا يُعاد فتح تصويت أُغلق ولا ترتيب أُنهي.
- تجميد حساب ناخب/كاتب/داعم يُخفيه من الأسطح العامة فورًا؛ تبقى دفاتره.

## 6. استكشاف الأعطال

| العَرَض | السبب الأرجح |
|---|---|
| لا أحد يستطيع التصويت لكاتب | لا سلسلة مربوطة له، أو خارج نافذة التصويت، أو اللاعب لم يحاول عملًا في سلسلته |
| «الإغلاق قبل نهاية الموسم بسبعة أيام» | الموسم بلا نهاية أو إغلاق متأخر |
| لا نقاط من شراء متجر | `support_points` = 0، أو لا موسم مؤهَّل، أو أكثر من موسم مؤهَّل (ابحث في السجل عن تنبيه الغموض) |
| بطاقة معلّقة | الدفعة لم تُتحقَّق بعد في مسار E32 |
| الترتيب الحيّ لا يتحدث | الاستطلاع الاحتياطي كل ~20 ث؛ تحقق من Reverb فقط للتحديث الفوري |

## 7. التحقق الحي من التزامن

سباق حقيقي بين عمليات PHP على MySQL (لا SQLite: أقفال الصفوف لا أثر لها هناك). **يمسح قاعدة الاختبار المؤقتة** (`migrate:fresh`) ويرفض أي قاعدة لا ينتهي اسمها بـ`_test`، فلا يُوجَّه لقاعدة العمل أبدًا.

```
$env:DB_CONNECTION='mysql'; $env:DB_DATABASE='ahjiyat_platform_test_mysql'; $env:DB_USERNAME='root'; $env:DB_PASSWORD='...'
php tools/e44/concurrency-probe.php              # 0 نجاح، 1 فشل فحص، 2 حاجز أمان
php tools/e44/concurrency-probe.php --rounds=8
```

يغطي: ميزانية 10 نجوم بين كتّاب متنافسين، إعادة توزيع الناخب نفسه، ستة ناخبين على كاتب واحد، توزيع متعاكس، سحب كاتب أثناء التصويت، ثلاثة إنهاءات متزامنة، منح/عكس المصدر نفسه من عدة عمليات، وإنهاء ترتيب الداعمين مع منح لجدد وقدامى وعكس متأخر؛ ثم مطابقة الدوري والداعمين وفحوص دفتر ↔ مجاميع. أي جمود (1213) أو انتظار قفل (1205) يُعدّ فشلًا.
