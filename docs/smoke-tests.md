
# اختبارات الدخان اليدوية (بعد كل نشرة - 15-20 دقيقة)

استخدم حساب اختبار مخوَّل - لا كلمة سر حساب إنتاج حقيقي بهذا الملف إطلاقًا.

## عام (بلا تسجيل دخول)

- [ ] `/` الصفحة الرئيسية تُحمَّل بلا خطأ.
- [ ] `/puzzles` تعرض الأحجيات المفعَّلة.
- [ ] `/seasons` و`/campaigns` تعملان.
- [ ] `/leaderboard` تعرض لوحة الصدارة.
- [ ] تسجيل دخول بحساب اختباري ناجح.
- [ ] تسجيل حساب جديد ناجح (إن كان `allow_registration` مفعَّلًا).

## اللاعب

- [ ] فتح أحجية وحلّها - الجواهر تُضاف (معلَّقة).
- [ ] لعبة Spot Difference تعمل من البداية للنهاية.
- [ ] فتح خطوة بحملة رسمية وإكمالها.
- [ ] صفحة `/wallet` تعرض الرصيد الصحيح.
- [ ] طلب استبدال جديد ينشأ بنجاح.

## الإدارة (Super Admin)

- [ ] `/admin/login` يعمل.
- [ ] `/admin` - القائمة الجانبية تعرض كل الموارد المتوقَّعة.
- [ ] `/admin/users` - تبويبات User 360 تعمل.
- [ ] تجميد حساب تجريبي ورفع تجميده.
- [ ] `/admin/operations` يعرض الأرقام الصحيحة.
- [ ] `/admin/analytics` - تغيير الفترة يُحدِّث الأرقام فعليًا.
- [ ] تصدير تقرير CSV واحد - يفتح بإكسل، العربية سليمة.
- [ ] `/admin/settings` - حفظ تغيير بسيط ينعكس بالواجهة العامة فورًا.

## RBAC

- [ ] دور محدود لا يرى تبويبات/تقارير مالية أو أمنية.

## الأمان

- [ ] `php artisan production:check` Exit Code صفر.
- [ ] رابط غير موجود - 404 عربية، لا Stack Trace.
- [ ] دخول لوحة الإدارة بحساب بلا `admin.access` - 403 عربي واضح.
